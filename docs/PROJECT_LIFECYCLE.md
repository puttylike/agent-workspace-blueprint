# Project Lifecycle

Lifecycle and phase are declared in the private registry. A phase is displayed
as one of `RESEARCHING`, `PLANNING`, `IMPLEMENTING`, `TESTING`, `REVIEWING`,
`WRITING`, `BLOCKED`, or `WAITING_FOR_USER`.

A numeric percentage is shown only when completed and total task counts are
available from the same logical task snapshot and total is greater than zero.
Zero tasks never implies either zero-percent or complete. The declared phase is
shown instead.

Creation, deletion, archival, task mutation, commits, pushes, agent changes,
pull-request changes, and file writes are not part of this read-only release.
